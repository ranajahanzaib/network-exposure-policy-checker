# Probe model

Generate a plan from the same policy and snapshot used for audit. Copy the binary and plan to an authorized independent machine for LAN, VPN, or Internet checks. `--vantage` and `--source-id` are operator declarations, not verified identities. Preview with `probe --dry-run` before connecting. Network Exposure Policy Checker connects only to exact plan targets and sends no application payload. Keep plans and evidence with controlled access; imported evidence must match the plan and snapshot and be fresh (24 hours by default).
