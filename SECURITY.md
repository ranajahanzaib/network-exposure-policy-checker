# Security policy

Report suspected vulnerabilities privately through [GitHub security advisories](https://github.com/ranajahanzaib/network-exposure-policy-checker/security/advisories/new). Include the affected version, reproduction steps, and likely impact. Please avoid publishing exploit details while the report is being investigated.

Network Exposure Policy Checker does not authenticate probe operators or sign evidence. See the [threat model](docs/threat-model.md) before relying on imported observations.
